# Social Network

## Description

This app sets up routes for users, thoughts connected to users, and reactions connected to thoughts; view all, create new, edit, delete.

## Installation

In the CLI, run these commands to get started:

> To install dependencies
```
npm i
```
> To run the application
```
npm run start
```

## Usage

Through this app, you can manage different users, connect them through friends. Each user can post thoughts in a blog like environment, with reactions like comments.
